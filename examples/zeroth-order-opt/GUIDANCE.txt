在 Jetson / Ubuntu 上，最常用的是直接装 build-essential：
```
sudo apt update
sudo apt install build-essential
```
装完后确认：
```
which g++
g++ --version
```
若能看到类似 /usr/bin/g++ 和版本号，再回到 build 目录重新跑：

```




cd llama.cpp
mkdir build
cd build 
cmake .. -DGGML_CUDA=ON

./bin/llama-perplexity -m /home/xplor/llama.cpp/Qwen3-8B-f32-finetuned_2.gguf -f /home/xplor/llama.cpp/examples/zeroth-order-opt/wiki.test.raw
